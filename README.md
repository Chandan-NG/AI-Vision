# AI Vision

AI Vision is a browser-based object detection web application that enables users to upload images and detect common everyday objects in real time directly within the browser using the pretrained **COCO-SSD** (MobileNet) computer vision model powered by **TensorFlow.js**. By leveraging a pretrained model, the application delivers immediate, production-ready inference without requiring dataset collection, manual labeling, expensive GPU servers, or custom training pipelines, while ensuring complete user privacy and zero latency through 100% client-side execution with interactive confidence threshold filtering and image export.

**Live Deployment:** [https://chandrashan.github.io/AIVision/](https://chandan-ng.github.io/AI-Vision/)
